Cómo funciona el control RFID

El servicio acceso-rfid.service mantiene una sola aplicación Python en ejecución. Flask atiende la web en un hilo de ese proceso; el lector y el controlador funcionan en el hilo principal. Los módulos importados son archivos del programa, no procesos separados.

Recorrido de una lectura

  1. El bucle de acceso_rfid.py lee el RC522 y entrega el UID al controlador.
  2. Si hay una captura de alta solicitada desde la web, estado_sistema.py conserva el UID para el formulario y esa lectura no abre la puerta.
  3. El controlador revisa bloqueo, retirada de tarjeta, modo y habilitación en padron_rfid.py.
  4. En acceso, una tarjeta habilitada abre. Mientras la puerta está abierta, se ignoran todas las lecturas. Al vencer el tiempo, se cierra; la tarjeta debe haberse retirado antes de iniciar otro ciclo.
  5. En combinación, solo se aceptan pasos de una secuencia configurada. Cada paso intermedio renueva el plazo privado de espera y mantiene cerrado el servo, sin mostrar avance. El último paso abre y muestra la palabra final. Un paso distinto o tardío reinicia la secuencia.
  6. El controlador actualiza el LCD, el servo y estado_sistema.py. El navegador consulta /api/estado para reflejar puerta, lector, bloqueo y modo.

Tres lecturas de UID no registrados bloquean durante 10 segundos. Cambiar de modo cancela una secuencia pendiente y cierra una apertura en curso. El tiempo configurado en el panel se usa tanto para la puerta abierta como para esperar el siguiente paso.
